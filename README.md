# ✦ 별별 작명소

> 엄마 아빠 이름에 담긴 뜻을 이어받아 아이 이름을 지어 드립니다.
> 결혼 · 육아 · 가족을 위한 웹서비스 **별마마파파**의 두 번째 서비스

빌드 도구 없이 도는 정적 사이트입니다. `main`에 push하면 GitHub Actions가
1~2분 안에 자동으로 배포합니다.

## 어떻게 짓는가

1. 아빠·엄마 이름을 적으면 **성(姓)을 떼어내고** 이름 글자만 남깁니다.
   (남궁·황보 같은 두 글자 성도 알아봅니다)
2. 각 글자를 어떤 한자로 쓰는지 고릅니다. 예) `은` → 恩(은혜) · 銀(은빛) · 慇(정성)
3. **닮음 정도**를 고르면 그만큼 부모 이름을 이어받습니다.

| 닮음 | 하는 일 |
|---|---|
| 0% | 부모 이름과 상관없이 새로 짓기 |
| 25% | 글자는 새로, 뜻 계열만 이어받기 |
| 50% | 부모 이름에서 한 글자 그대로 |
| 75% | 한 글자 그대로 + 나머지도 같은 뜻 계열 |
| 100% | 아빠·엄마 이름에서 각각 한 글자씩 |

4. 성별 · 자수 · 꼭 넣을 글자(또는 초성)를 맞춰 이름을 고릅니다.
5. 한자 이름이면 **뜻풀이**까지 만들어 줍니다.
   예) 恩(은혜 은) + 珍(보배 진) → **은혜로운 보배**

조건이 너무 빡빡해 맞는 이름이 없으면, 뜻 계열 → 글자 자리 → 성별 순으로
조건을 하나씩 놓아 가며 다시 찾습니다.

## 구성

```
index.html   화면
styles.css   밤하늘 · 금빛 무드 (별마마파파 브랜드)
data.js      이름 글자 사전 — 한자 · 뜻 · 성별/자리 성향
app.js       이름 짓기 · 로딩 연출 · 모달 · 공유
assets/      로고
```

### 글자 사전 늘리기

`data.js`의 `SYL`에 글자를 더하면 바로 쓸 수 있습니다.

```js
윤: { g: "N", p: "b", h: [
  { c: "潤", m: "윤택함", a: "윤택한", j: "윤택하고", t: "abundance" },
]},
```

- `g` 성별 성향 — `M` 남아 · `F` 여아 · `N` 상관없음
- `p` 자리 성향 — `1` 앞글자 · `2` 뒷글자 · `b` 둘 다
- `m` 뜻 · `a` 관형형(…한) · `j` 연결형(…하고)
- `t` 뜻 계열 — 닮음 25%·75%에서 부모 한자와 맞춰 보는 값

뜻이 **손에 잡히는 말**(별·보배·바다처럼)이면 `CONCRETE`에도 넣어 주세요.
뜻풀이의 마지막 자리에 놓이면서 "은혜로운 **보배**"처럼 읽힙니다.

## 카카오톡 공유

`app.js` 맨 위의 `KAKAO_JS_KEY`에 카카오 JavaScript 키를 넣으면 카톡으로 바로
공유됩니다. 비워 두면 기기의 공유 기능이나 링크 복사로 대신합니다.

키를 넣을 때는 [카카오 개발자센터](https://developers.kakao.com)에서
**플랫폼 → Web → 사이트 도메인**에 배포 주소를 등록해야 합니다.

## 로컬에서 보기

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## 배포

저장소 **Settings → Pages → Source**를 `GitHub Actions`로 두면 끝입니다.
이후 `main`에 push할 때마다 워크플로가 알아서 배포합니다.
