# ✦ 별별 작명소

> 엄마 아빠 이름에 담긴 뜻을 이어받아 아이 이름을 지어 드립니다.
> 결혼 · 육아 · 가족을 위한 웹서비스 **별마마파파**의 두 번째 서비스

빌드 도구 없이 도는 정적 사이트에, 결과 카드 그림을 그려 주는 자리 하나를
얹었습니다. `main`에 push하면 Vercel이 1~2분 안에 자동으로 배포합니다.

## 어떻게 짓는가

1. 아빠·엄마 이름을 적으면 **성(姓)을 떼어내고** 이름 글자만 남깁니다.
   (남궁·황보 같은 두 글자 성도 알아봅니다)
2. 각 글자를 어떤 한자로 쓰는지 고릅니다. 예) `은` → 恩(은혜) · 銀(은빛) · 慇(정성)
3. **닮음 정도**를 고르면 그만큼 부모 이름을 이어받습니다.

| 닮음 | 하는 일 |
|---|---|
| 0% | 부모 이름과 상관없이 새로 짓기 |
| 25% | 글자는 새로, 뜻 계열만 이어받기 |
| 50% | 부모 이름에서 한 글자 그대로 |
| 75% | 한 글자 그대로 + 나머지도 같은 뜻 계열 |
| 100% | 아빠·엄마 이름에서 각각 한 글자씩 |

4. 성별 · 자수(외자 · 두 글자 · 세 글자) · 꼭 넣을 글자를 맞춰 이름을 고릅니다.
5. 한자 이름이면 **뜻풀이**까지 만들어 줍니다.
   예) 恩(은혜 은) + 珍(보배 진) → **은혜로운 보배**

조건이 너무 빡빡해 맞는 이름이 없으면, 뜻 계열 → 글자 자리 → 성별 순으로
조건을 하나씩 놓아 가며 다시 찾습니다.

**순우리말 이름의 닮음** — 순우리말은 글자를 짜맞추지 않고 손질해 담아 둔
이름 가운데서 고릅니다. 그래서 50% 이상이면 부모님 이름 글자를 품은 이름만
내놓습니다(100%면 아빠·엄마 글자를 둘 다). 그런 이름이 없거나 이미 다
보여 드렸으면 다음 둘로 갈라 굴러갑니다.

- **앞서 다 보여 드려서 남지 않았을 때** — 한자 이름과 똑같이 "모두 보여
  드렸어요" 화면과 `다시 보기` 를 드립니다. 누르면 기억을 지우고 처음부터
  다시 닮은 이름을 지어 드립니다.
- **그런 이름이 애초에 없을 때** — **닮음을 몰래 풀지 않고 없다고 알려
  드립니다.** 자수만 바꾸면 되는지, 닮음을 낮춰야 하는지까지 짚어 줍니다.

조용히 닮지 않은 이름을 내면 부모님 이름을 썼는 줄 아시게 되기 때문입니다.
한자 이름도 물려받기는 풀지 않으므로(뜻 계열 · 자리 · 성별만 풉니다) 결이
같습니다.

고를 수 있는 초성도 닮음에 맞춰 잠급니다. 김선일 · 박은진 두 분에 닮음 50%
라면 두 글자 순우리말은 `은결` · `어진` · `곧은` 뿐이라, 첫 글자는 ㄱ · ㅇ
만 고를 수 있습니다.

**한 글자에 뜻이 여럿일 때** — 忯 은 사전에 `믿음`으로 담아 두었지만
`사랑할`로 새기기도 합니다. 직접 입력 칸에 **뜻을 함께 적으시면 그 뜻이
사전보다 앞섭니다** (`사랑할 지 忯`).

**뜻으로 한자 찾기** — 고르는 칸에는 자주 쓰는 글자만 담습니다. 그 소리로
읽는 한자가 지 자리에 210자, 유 자리에 492자나 되어 다 늘어놓으면 고를 수가
없기 때문입니다. 대신 `✎ 직접 입력 · 찾기` 를 골라 **뜻을 적으면 그 소리로
읽는 한자를 찾아 눌러 고를 수 있습니다** — 지 자리에 `사랑` 이라 적으면
`忯 · 사랑할` 이 나옵니다. 훈음 표 27,292자를 모두 뒤집니다.

새김이 그 소리에 매인 것만 보면 忯(믿을 지 · 사랑할 기)에서 사랑을 찾을 수
없으므로, 그 글자의 새김은 소리를 가리지 않고 모두 봅니다. 어떻게 읽고 어떤
뜻으로 쓰시는지는 그 이름을 가진 분이 가장 잘 아십니다.

## 구성

```
index.html   화면
styles.css   밤하늘 · 금빛 무드 (별마마파파 브랜드)
data.js      이름 글자 사전 — 한자 · 뜻 · 성별/자리 성향
app.js       이름 짓기 · 로딩 연출 · 모달 · 공유
hanja-hun.json  한자 2만 7천 자의 훈음 (부모님 이름을 읽는 데만 쓴다)
assets/      로고
```

### 사전 둘

`data.js` 의 `SYL` 은 **아이 이름을 짓는** 사전입니다. 좁게 담습니다 —
아무 한자나 넣으면 있을 법하지 않은 이름이 나오기 때문입니다.

`hanja-hun.json` 은 **부모님 이름을 읽는** 표입니다. 부모님 이름에는
사전 밖의 글자가 얼마든지 오므로(忯 · 㴗 처럼) 훈음만 따로 널찍이
담아 둡니다. 이름 후보로는 절대 쓰지 않고, 직접 입력하신 한자의 뜻을
알아보는 데에만 씁니다. 화면을 여는 데 짐이 되지 않게 부모님 이름을
적으실 때 그제야 받아 옵니다.

```bash
# 다시 만들 때
npm i --no-save @seyoungsong/hanjadict hanja
node tools/build-hun-table.js > hanja-hun.json
```

### 글자 사전 늘리기

`data.js`의 `SYL`에 글자를 더하면 바로 쓸 수 있습니다.

```js
윤: { g: "N", p: "b", h: [
  { c: "潤", m: "윤택함", a: "윤택한", j: "윤택하고", t: "abundance" },
]},
```

- `g` 성별 성향 — `M` 남아 · `F` 여아 · `N` 상관없음
- `p` 자리 성향 — `1` 앞글자 · `2` 뒷글자 · `b` 둘 다
- `m` 뜻 · `a` 관형형(…한) · `j` 연결형(…하고)
- `t` 뜻 계열 — 닮음 25%·75%에서 부모 한자와 맞춰 보는 값
- `x: 1` **부모님 이름을 읽어 드릴 때만 쓰는 글자**

`x: 1` 은 부모님 이름을 읽는 데에만 쓰는 한자에 붙입니다. 고르는 자리에는
그대로 보이지만 새 이름을 지을 때는 뽑지 않습니다. 부모님이 직접 고른
글자는 물려받을 때 그대로 씁니다. 음절 자체가 부모님 세대의 것이면
`o: 1` 로 음절째 빼 둡니다.

닫아 두는 까닭은 넷뿐입니다 — 성씨나 나라 이름으로 먼저 읽히거나(李 · 韓),
뜻이 이름에 얹히지 않거나(那 · 有), 옛 벼슬·왕실 말이라 무겁거나(卿 · 妃),
카드 글꼴에 없어 한자를 못 보여 주거나(忯). 그 밖에는 열어 둡니다.

직접 적어 주신 새김은 훈음 표 그대로 ㄹ로 끝납니다(`깊을` · `사랑할`).
그대로 이으면 어색하므로 우리 말꼴로 두릅니다.

| 새김 | 꾸미는 꼴 | 잇는 꼴 |
|---|---|---|
| 깊을 | 깊은 | 깊고 |
| 사랑할 | 사랑이 가득한 | 사랑이 |
| 고울 | 고운 | 곱고 |
| 클 | 큰 | 크고 |

`-하다`에서 온 말은 이름씨를 되찾습니다 — `사랑하고 깊은` 보다 **`사랑이
깊은`** 이 우리 말에 가깝기 때문입니다. `고울` 처럼 ㅂ이 빠진 말은 이을 때
되돌립니다(`곱고`).

뜻이 **손에 잡히는 말**(별·보배·바다처럼)이면 `CONCRETE`에도 넣어 주세요.
뜻풀이의 마지막 자리에 놓이면서 "은혜로운 **보배**"처럼 읽힙니다.

## 카카오톡 공유

`app.js` 맨 위의 `KAKAO_JS_KEY`에 카카오 JavaScript 키를 넣으면 카톡으로 바로
공유됩니다. 비워 두면 기기의 공유 기능이나 링크 복사로 대신합니다.

키를 넣을 때는 [카카오 개발자센터](https://developers.kakao.com)에서
**앱 → 제품 링크 관리 → 웹 도메인**에 배포 주소를 등록해야 합니다.
등록되지 않은 도메인의 링크는 카카오가 그대로 보내지 않습니다.

## 로컬에서 보기

이름 짓기 화면만 볼 때는 정적 서버로 충분합니다.

python3 -m http.server 8000
# http://localhost:8000
```

```

## 결과 카드 그림 (`/api/card`)

카카오톡 공유 카드에 들어가는 그림은 **카카오 서버가 가져갈 수 있는 주소**라야
합니다. 그래서 브라우저에서 그린 그림을 그대로 얹지 못하고, 같은 그림을 그려
주는 자리를 따로 두었습니다.

```
/api/card?n=김도선&h=道善&r=도리 도 道,착함 선 善&m=올곧고 착한 아이
```

- 이름은 한글, 한자는 한자, 뜻은 한글과 몇몇 문장부호까지만 받습니다.
  누구나 부를 수 있는 자리라, 우리 이름표가 박힌 그림으로 엉뚱한 말이
  퍼지지 않도록 막아 둔 것입니다.
- 이름이 같으면 별자리까지 같은 그림이 나오므로 오래 담아 두어도 됩니다
  (`Cache-Control: immutable`).

> **카드 모양이나 글꼴을 손보았으면 `app.js` 의 `CARD_V` 를 올려 주세요.**
> 주소마다 오래 담아 두게 해 두었으므로, 번호를 올려 주소를 바꾸지 않으면
> 이미 담긴 곳에서는 옛 그림이 그대로 나갑니다. 카카오도 한 번 가져간
> 그림을 붙들고 있습니다.

**글꼴** — 고운바탕에는 한자가 없고, 여러 조각을 한 이름으로 등록해도 글자
범위가 합쳐지지 않습니다. 그래서 고운바탕(한글·라틴)에 한자를 Noto Serif KR
에서 뽑아 붙인 파일을 만들어 씁니다.

```bash
# 사전에 한자를 더한 뒤에는 다시 만들어 주세요.
# 원본 글꼴이 필요하니 먼저 받아 둡니다. (마지막 것은 160MB 남짓입니다)
npm i --no-save @fontsource/gowun-batang @fontsource/noto-serif-kr \
                @fontpkg/source-han-serif-k
python3 tools/build-card-font.py api/fonts/byeol-card.woff2
```

글꼴은 두 벌입니다. 앞은 고운바탕(한글)에 **Noto Serif KR 의 한자
4,644자**를 붙인 `byeol-card.woff2`, 뒤는 **Source Han Serif K 에서 뽑은
나머지 22,560자**를 담은 `byeol-card-tail.woff2` 입니다. 카드는 두 벌을
차례로 세워 씁니다(`"ByeolCard", "ByeolCardTail"`).

Noto Serif KR 은 한국어에 쓰는 한자만 담고 있어 부모님이 적어 주신 드문
글자(忯 · 㴗)가 빠집니다. 둘은 본디 같은 글꼴이라(Noto Serif CJK KR =
Source Han Serif K) 나란히 놓아도 티가 나지 않습니다. 한 파일로 합치지
않는 것은 바깥 모양을 담는 방식이 달라서입니다(glyf ↔ CFF).

뒤 글꼴은 자리잡기·힌팅 표를 덜어 5.2MB 로 담았습니다(그대로면 13.5MB).

만들 때 `byeol-card-glyphs.txt` 도 함께 나옵니다. 이 글꼴로 그릴 수 있는 한자
목록이고, `/api/card` 가 이것을 보고 못 그릴 한자가 섞였으면 **한자 줄을 통째로
접습니다**. 한 글자만 빼면 이름이 잘못 적힌 것처럼 보이기 때문입니다. 이름과
뜻풀이는 그대로 나옵니다.

그래서 Noto Serif KR 에 없는 한자(만들 때 `!! 빠진 한자:` 로 알려 줍니다)를
사전에 두어도 두부(□)가 나오지는 않습니다. 다만 그 이름은 카드에서 한자를
못 보여 주니, 되도록 그릴 수 있는 글자로 담아 주세요.

## 배포 (Vercel)

`main` 에 push 하면 Vercel 이 알아서 올립니다. 정적 파일은 그대로 서비스하고,
`api/` 아래는 서버리스 함수로 잡힙니다. 빌드 명령은 없습니다.

`vercel.json` 에 글꼴 파일을 함수에 딸려 보내는 설정이 들어 있습니다.
`@napi-rs/canvas` 는 네이티브 라이브러리라 **Node 런타임**에서만 돕니다.

**고친 것이 안 보일 때** — `index.html` 은 늘 새로 확인하도록 `vercel.json` 에
`Cache-Control: max-age=0, must-revalidate` 를 걸어 두었습니다. 화면 파일이
묵으면 `styles.css?v=…` 를 올려도 브라우저가 옛 주소만 계속 불러서, 고친
것이 닿지 않습니다. css · js 를 고쳤으면 `index.html` 의 `?v=` 도 함께
올려 주세요.

## 도메인 (naming.byeolmamapapa.com)

**DNS (도메인 구입처에서)**

| 타입 | 호스트 | 값 |
|---|---|---|
| CNAME | `naming` | Vercel 이 Domains 화면에 알려 주는 값 |

Vercel 프로젝트 **Settings → Domains** 에 주소를 넣으면 어떤 레코드로 바꿔야
하는지 알려 줍니다. 서브도메인은 A 레코드가 아니라 **CNAME** 입니다.

> Cloudflare 를 거친다면 그 레코드의 프록시(주황색 구름)를 꺼 두세요.
> 켜져 있으면 인증서 발급이 막힙니다.

주소를 바꾸려면 `index.html` 의 canonical · og:url · og:image · JSON-LD,
그리고 `robots.txt` · `sitemap.xml` 의 주소도 같이 고쳐야 합니다.
